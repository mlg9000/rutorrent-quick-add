# Contributing

Issues and pull requests are welcome.

- Reproduce the issue on a current Firefox release.
- Describe your ruTorrent/rTorrent version, reverse-proxy setup, and expected/actual behavior.
- Never post credentials, private hostnames, tracker passkeys, private magnet URLs, or unredacted torrent lists.
- Keep dependencies minimal; prefer browser APIs and readable vanilla JavaScript.
- Run `node --check` on modified JavaScript files.
- Test magnet links, `.torrent` URLs, multi-server switching, and verification behavior before proposing changes.

For security-sensitive reports, avoid publishing secrets in public issues.
